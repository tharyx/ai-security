# LinkedIn Post Template

Aim for 800 to 1300 characters. Put the first line as a hook, because LinkedIn shows only the first lines before "see more". Put links in the first comment or at the end, not the middle. Do not claim skills you do not have. Do not post flags, answers for active platform content, exam questions or employer data.

## Template A: a lab I finished

```text
[Hook: one clear sentence about the result]
Example: "I wrote 5 cloud detections in Python and tested them against normal admin work."

Why: [1 sentence about the real problem]

What I built:
- [Point 1]
- [Point 2]
- [Point 3]

What I learned: [1 or 2 sentences, honest]

One thing that surprised me: [1 sentence]

Code and notes: [link]

#CloudSecurity #SOC #DetectionEngineering
```

## Template B: a DBA to security bridge

```text
[Hook: "As an Oracle DBA I already did security work. I just did not call it that."]

[DBA habit] = [security name]
[DBA habit] = [security name]
[DBA habit] = [security name]

Now I use these ideas for [new task, e.g. reading audit logs in a SIEM].

If you are a DBA thinking about security: [one practical tip].

Notes and labs: [link]

#DatabaseSecurity #CareerChange #Oracle
```

## Template C: a weekly learning note (short)

```text
Week [N] in my cybersecurity track.

Studied: [module]
Practiced: [room or lab, no answers]
Built: [small thing]
Next: [one goal]

Question for people in the field: [one specific question]
```

## Rules

1. One post per week or two. Quality over volume.
2. Reply to comments within a day. Ask and answer questions.
3. Tag people only when they contributed. Credit sources.
4. Check: facts, links, spelling, secrets, rules of the platform.
5. Add the post to `trackers/blog-posts.md` (platform: LinkedIn).
